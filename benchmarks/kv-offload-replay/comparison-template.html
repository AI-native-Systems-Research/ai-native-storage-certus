KV-offload backend comparison

Total wall time

Seconds to replay the full workload. Lower is better; the sub-label is the ratio vs the first backend.

Offload-tier prefix-cache queries per round

Blocks the engine looked for in the external (offload) tier each round. NoOffload has no external tier → 0.

Offload-tier prefix-cache hits per round

Blocks actually served from the offload tier each round. hits ÷ queries is the tier's per-round hit rate.

Bytes read from tier per round

Physical bytes pulled from the backing store each round (SSD/RAID for Certus & SharedStorage; ~0 for RAM tiers).

Data table
Fill RUN and BACKENDS at the top of the script from a profile_all.sh run. queries/hits ← prom_counters_rounds.json (vllm:external_prefix_cache_queries|hits); read_bytes ← per-round ssd_read/disk_read log deltas; total ← results.json.
