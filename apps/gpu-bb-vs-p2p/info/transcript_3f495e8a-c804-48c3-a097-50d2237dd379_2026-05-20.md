The main bottleneck is that `cudaMemcpyAsync` is likely **falling back to synchronous mode** because SPDK hugepage buffers aren't registered with CUDA as pinned memory. 1. **Register SPDK buffers with CUDA** — call `cudaHostRegister` on each ring buffer after allocation. This tells CUDA's DMA engine the physical addresses are stable, enabling true async H2D:
