Code assumptions (5)

Assumptions the code makes that the specification does not state. The specification may deliberately leave room here, so these are not faults; writing them down is the point. Every property that depends on one is formally verified under it (the scoring page says "Verified for: …"). Only a failure inside an assumption would be a defect.

1the memory-tier byte size is at most 4,294,963,200 bytes (4 GiB minus 4 KiB), so its rounded-up size fits in 32 bitsrangecreate_memory_tier_entry, promote_block_to_memory_tier, entry_sizeA memory-tier entry may have any non-zero 32-bit byte size, and entry_size must report that size rounded up to a whole number of 4 KiB blocks, as a 32-bit value (FR-003, FR-023, FR-025).
