9Candidates listed in eviction orderget_eviction_candidates, identify_next_to_evictThe candidates are listed in the order the policy would actually evict them, oldest access first, so the first candidate in the list is exactly the block a victim request would return at that moment, the second is the one after that, and so on.Beyond its first entry, the candidate list is not in general the order in which blocks will actually be evicted.
